# 通用约束（始终生效）

## 安全

- AI 生成结果**绝不自动写入**世界书或其它持久存储，必须先进 Diff 预览由用户确认。
- 动态内容入 DOM 前转义；用户输入的文本**不得**直接拼进 `innerHTML`。
- 构造正则时注意 ReDoS（嵌套量词、灾难性回溯）——本项目已有拦截逻辑，
  新增正则要走同样的审查。
- 文件路径操作需过滤 `..` 穿越。
- 不要写入真实 API key、`.env`、用户世界书数据到仓库。
- 提交前扫一遍：无硬编码密钥、无 `.env`、无自定义 git hook。

## 不可逆操作

以下动作**必须先在回复里说明影响范围并取得主人明确确认**，不要自作主张：

- `git push`（外部动作）
- `git reset --hard` / `git checkout --` / `git clean`（丢弃工作区改动）
- 删除文件或目录
- 覆盖已有配置文件
- 在仓库外做系统级修改（注册表、环境变量、软件安装）

改代码、跑测试、创建新文件可以直接做——这些可逆且在授权范围内。

## 沟通

- 中文回复。
- 结论先行，不要「好的，我来帮你…」这类开场。
- 给**文件路径 + 行号**作为证据，不要只说「已修复」。
- 结尾给「接下来做什么」的明确清单。
- 不确定的地方直接说不确定，不要含糊过关。
