01

设计语言总览

v2.0.1「Flat Glass（扁平玻璃）」的三条硬规则：静态区块扁平、玻璃只用于浮层、动效有意义且可降级。 判断一个表面该不该上玻璃，只看它是不是浮层。

扁平优先

按钮、折叠、徽标、输入、标签页等静态区块只靠色阶与间距表达层级： 不加 1px 描边、不加投影、不用渐变。视觉边界交给 --nvui-block-bg / -bg-2。

玻璃只用于浮层

弹窗、遮罩、悬浮面板、工具提示、吐司与任意 .nvui-glass 容器：半透明底 + backdrop-filter 模糊/饱和；v2.2.0 起圆角玻璃外框 不再画 1px 描边（避免圆角处的亚像素锯齿），改由柔和的顶部受光 （--nvui-glass-highlight）+ 阴影与模糊成形；直线分隔继续用 --nvui-glass-line。

动效有意义且可降级

动效只表达层级、方向与因果；全部尊重 prefers-reduced-motion 与 prefers-reduced-transparency， 玻璃能力缺失时回退为不透明表面。

AA AA 安全玻璃（v2.0.1 新口径，按 sRGB 逐通道合成）：深色弹窗级玻璃叠纯白宿主的最坏情况为 正文 10.33:1 / 次要文字 4.70:1；深色 popover 级只承诺正文 --nvui-text = 7.76:1 —— popover 玻璃上的说明文字也必须用 --nvui-text， 不要用 --nvui-text-2。浅色弹窗级叠纯黑宿主为 9.31:1 / 4.64:1， 浅色 popover 级为 9.66:1 / 4.81:1。弹窗级玻璃上的正文与次要文字始终不低于 4.5:1， 提示性小字 --nvui-text-3 只用于非关键信息。
v2.0.0 破坏性变更 v2.0.1 观感修订 v2.1.0 面板布局标准 v2.1.1 描边再减弱 v2.2.0 描边精致化 + API 折叠面板新增 .nvui-acc-inner；删除 --nvui-shadow-accent；v2.0.1 玻璃更透（0.64 / 0.80）、关键帧增至 16 个；v2.1.0 新增桌面面板/手机底部抽屉布局（10 个类 + 2 个尺寸令牌）；v2.1.1 描边整体减弱、焦点环收细、面板固定尺寸、滚动条隐藏；v2.2.0 圆角玻璃外框去掉 1px 描边（消除锯齿）、直线分隔用玻璃分隔色、焦点环单圈 2px，并新增 nvui-api.js / tokens.json / AI-GUIDE.md。

默认中性、主操作用 is-primary（每屏建议最多 1 个）、次级 is-secondary、 弱操作 is-ghost（v2.2.0：去掉 1px 描边、改用 --nvui-block-bg 淡底）、破坏性 is-danger； 悬停只改背景与文字色，不加投影。

按压反馈：:active 时按钮缩放到 0.97（图标按钮 0.92），松开回弹； hover 只提亮一档背景。主按钮文字色走 --nvui-on-accent，不再借用开关滑钮的 --nvui-knob； 焦点环统一走 --nvui-focus-ring-*（v2.2.0：2px 整数像素单圈），只在 :focus-visible 出现。 v2.2.0 起 ghost 按钮去掉 1px 描边、改 block-bg 淡底；空态去掉虚线圆角边。

输入行

左标题 + 右控件；数值框定宽右对齐，路径框定宽且窄屏不超过行宽 60%。 v2.2.0：聚焦为单圈 2px 焦点环（--nvui-focus-ring-w = 2px，整数像素更清晰）， 不再叠加内圈描边，只保留一圈清晰边界。

点击后聚焦上面的「单图上限」输入框，观察单圈 2px 焦点环； 页面载入不会自动聚焦，避免抢走初始焦点。

输入框底使用 --nvui-input-bg，占位符用 --nvui-text-3； v2.2.0 聚焦只画一圈 outline: var(--nvui-focus-ring-w)（2px）solid var(--nvui-focus-ring-color)， 不再叠加 inset 内圈描边。 v2.0.1：数字输入框隐藏浏览器原生步进按钮（暗色下不再出现白色小箭头）， 键盘 ↑/↓ 与滚轮仍可调值，需要可见步进器请自建 .nvui-icon-btn。

08

标签页（粘连指示器）

nav[role=tablist] + button[role=tab] + 面板 [role=tabpanel]；只切 is-active 与 aria-selected，不重建 DOM。 v2.0.1 追加「粘连」指示器：.nvui-tabs-indicator 用 --nvui-tab-ind-x/y/w/h 定位， 切换时先把指示器拉长到「旧位置 ∪ 新位置」，requestAnimationFrame 两帧后收缩到目标 （stretch-then-settle），配合 spring 缓动呈现「滑过去」的质感；无 JS 时自动回退为按钮自身高亮。 本机系统若开启「减少动态效果」，请打开顶部「强制播放动效」再观察。

面板一：标签页只切 is-active 与 aria-selected，切换时建议把滚动位置复位，异步结果不受影响。
面板二：过滤条件存在面板内部，切换标签不重建 DOM，输入态不会丢。
面板三：内容可以继续嵌套折叠分组与开关行。

键盘 ←/→/Home/End 与点击走同一套切换逻辑，并同步 tabindex / aria-selected； 点击或键盘切换时 JS 会先加 .nvui-tabs.is-indicator 接管选中底色（按钮不再播 nvui-tab-select，避免双重动画）， 指示器随后按 stretch-then-settle 滑到目标；无 JS 时按钮保留自身 is-active 高亮作为回退。 面板入场仍播 nvui-tabpane-in（淡入 + 上移 6px，base + emphasized）。 v2.2.0：指示器去掉 1px 内环，改成底部直线强调（inset 0 -2px 0 --nvui-accent-line）， 不再出现圆角内描边。 顶部「强制播放动效」或 ?motion=1 可完整观察指示器粘连滑动与面板入场。

弹窗与 top-layer 载体

真实插件中必须把弹窗挂进 dialog.nvui-tl 并用非模态 show() 提升层级 （避免酒馆 html transform 把 fixed 浮层顶出屏幕，也避免 showModal 的 inert 让其它入口点不到）。

  1. 打开：dialog.show()（兜底 setAttribute('open','')）后把遮罩 hidden 置 false；遮罩播放 nvui-overlay-in，弹窗播放 nvui-modal-in（上移 14px + 0.97 缩放 + 淡入）。
  2. 关闭：给遮罩加 is-closing，等遮罩的 animationend（或 320ms 兜底）后隐藏遮罩并 dialog.close()；遮罩播放 nvui-overlay-out，弹窗播放 nvui-modal-out。
  3. 关闭入口：右上角 ×、底部取消、Esc、点击遮罩；关闭后焦点回到打开它的按钮。
  4. 非模态 show() 不会给文档加 inert，页面上其它入口仍可点击；载体本身 pointer-events: none。

本页共三个 dialog.nvui-tl 顶层载体：弹窗层、吐司层、工具提示层。 弹窗本体使用 --nvui-glass-bg 0.64 + --nvui-glass-blur 20px 的玻璃表面与 --nvui-radius-xl 大圆角， 圆角玻璃外框无 1px 描边（v2.2.0，靠顶部柔光 + 阴影成形、无锯齿），直线分隔用 --nvui-glass-line。 进出场动画（遮罩 nvui-overlay-in/out、弹窗 nvui-modal-in/out、折叠 grid-template-rows 过渡） 可在顶部「强制播放动效」下观察——本机系统开启「减少动态效果」时默认会被浏览器降级到 0.01ms。

可访问性与能力降级

玻璃能力不是所有环境都有：组件在系统偏好、浏览器能力、宿主样式缺失时都必须回退到可读的不透明表面， 并且所有动效都能被「减少动态效果」关掉。

prefers-reduced-motion: reduce

动画时长降为 0.01ms、只播 1 次、animation-delay 一并归零，过渡时长同步降级；不靠动画才能读到的信息不会丢失。本页顶部的「强制播放动效」只是演示开关（仅本页、默认关闭），生产代码不得照抄该覆盖，必须继续尊重系统偏好。

prefers-reduced-transparency: reduce

玻璃表面回退为不透明 --nvui-bg / --nvui-bg-2，并移除 backdrop-filter；内容层级不变，只是不再透出宿主。

@supports not (backdrop-filter)

浏览器不支持模糊时，弹窗级回退不透明 --nvui-bg，popover 级回退 --nvui-bg-2；每个声明同时带 -webkit- 前缀兼容 Safari。

forced-colors: active

高对比模式下玻璃表面加 1px solid CanvasText 系统色描边，保证边缘可见；不覆盖系统强制色值。

.nvui-solid 实心扁平模式

在根节点叠加 .nvui-solid 后，全部玻璃表面回退为不透明 --nvui-bg / --nvui-bg-2 且 backdrop-filter: none；顶部「切换实心扁平模式」即可体验。

焦点环统一走 token

所有可交互元素只在 :focus-visible 时显示 outline: var(--nvui-focus-ring-w) solid var(--nvui-focus-ring-color)，偏移用 --nvui-focus-ring-offset，不再各写像素值。v2.2.0：宽度统一 2px 单圈（整数像素更清晰），不再叠加内圈描边。

键盘与语义

弹窗支持 Esc 与遮罩点击关闭，关闭后焦点回到触发按钮；标签页、折叠、开关均维护 aria-selected / aria-expanded / role；吐司使用 role="status"。

减少动态效果下的玻璃

动效降级不改变玻璃的可读性：玻璃的 AA 对比度由 token 取值保证，与动画是否播放无关；窄屏自动改用 --nvui-glass-blur-sm 降低 GPU 开销。

SillyTavern 插件面板布局标准（桌面 / 手机）

同一份 DOM 在电脑与手机自动切换排列：电脑是居中面板（顶部标题栏 → 顶部分区 tabs → 可滚动内容 → 可选底部操作区），手机是底部抽屉（拖拽把手 → 标题栏 → 可滚动内容 → 底部图标导航）。 ≤600px 时由 components.css 自动切换，不需要两套 DOM。排列参考用户提供的插件面板截图， 颜色 / 玻璃 / 圆角 / 动效一律使用本 Kit 的 Flat Glass（紫色强调），不复制他插件皮肤。 点下方按钮打开真实 demo，或用 ?panel=1 载入即开。

排列标准（两套布局共用同一顺序）

  1. 顶部标题栏 .nvui-panel-header：.nvui-panel-title + .nvui-panel-actions（快速设置 + 关闭两个 .nvui-icon-btn）。
  2. 分区导航：电脑用顶部 .nvui-tabs（5 个 role=tab，共享 .nvui-tabs-indicator 粘连指示器）；手机隐藏顶部 tabs，改用底部 .nvui-bottom-nav 图标导航。
  3. 可滚动内容 .nvui-panel-body：.nvui-panel-heading（分区标题 + 版本 .nvui-badge）→ .nvui-switch-row.is-feature 高亮功能行 → 6 个 .nvui-acc 折叠分组（基本设置 / 副 API / 自动生成 tag / 排除角色 / 排除世界书内容 / 自定义提示词）。
  4. 可选底部操作区 .nvui-panel-footer（取消 / 保存）；手机端底部导航自动叠加 env(safe-area-inset-bottom)。
  5. 固定尺寸防跳变（v2.1.1 / v2.5.0）：面板桌面宽 min(720px, 100%)、高 88vh；手机全宽、高 92dvh —— 折叠/展开、切换 tab 都不会改变外框。.nvui-panel-body 是唯一滚动层，滚动条已隐藏（仍可滚动，内容超高时内部滚动）。
  6. 无障碍：panel 用 role="dialog" aria-modal="true" aria-labelledby；顶部 tabs 用 tablist/tab/tabpanel；底部导航用 nav + button，激活项 aria-current="page"，两套导航共用同一份 JS 同步 active 状态与 tabpane。
